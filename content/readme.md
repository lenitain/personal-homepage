# lenitain's homepage

Welcome. Navigate with your keyboard:

| Key              | Action           |
| ---------------- | ---------------- |
| `↓`              | Move down        |
| `↑`              | Move up          |
| `Enter` / `→`    | Open dir         |
| `Esc` / `←`      | Go to parent dir |

Use the file browser on the left to explore.
Content appears on the right.

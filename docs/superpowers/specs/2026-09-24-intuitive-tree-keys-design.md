# 键盘交互改版：删掉 readme 键位表，操作对齐文件管理器直觉

- 日期：2026-09-24
- 状态：已实施
- 影响范围：`src/routes/+page.svelte`、`src/lib/tree-nav.ts`（新增）、`src/lib/browse-state.ts`、`content/readme.md`、`content/projects/yazi-homepage.md`
- 不涉及：配色、字体、粉笔滤镜、演示模式的翻页键、左栏开合的窄边条、构建配置

## 背景

`content/readme.md` 里曾有一张键位表，外加两段解释（「The arrow keys only move the
highlight — press `Enter` to actually open something」）。**一张需要教的基础导航表是
交互失败的信号**：它在给 2026-09-11 spec 的编辑器语义打补丁（决策 #3「光标 ≠ 打开」、
#4「只保留 ↑↓ Enter」）。编辑器里两态分离是为了预览 tab 不乱跳；本站是阅读站，预览
零成本（正文随 SSR 内联、零请求），分离只换来一份说明书。

## 目标

操作符合用户**已经会的东西**的直觉 —— 文件管理器。做完之后 readme 里**不再有任何
交互说明**：一个键、一句「怎么操作」都不提。

## 决策

| # | 决策 | 结论 |
| --- | --- | --- |
| 1 | `↑`/`↓` | **选中即所见**：移动光标的同时右栏跟着换。`Enter` 保留但降级为别名（= 确认打开，无条件新开历史）。**落点与当前位置相同**（如最后一行还按 `↓`、首字母只有自己匹配）= 纯无操作：不写 URL、不动历史 —— 否则一次原地不动会凭空 push 出一条 `?file=` 记录 |
| 2 | `→`/`←` | 资源管理器 / ARIA 树约定：`→` 展开折叠的目录、走进已展开目录的第一个子项；`←` 收起展开的目录、跳到父行。两种情况一律 `preventDefault` —— 部分浏览器 `←`/`→` 是历史后退/前进，树活着的时候不许被偷走 |
| 3 | `Home`/`End`/`PageUp`/`PageDown` | 列表控件标配。一页 = `PAGE_STEP = 10` 行：树只有几十行，不值得为量视口引入 DOM 测量 |
| 4 | 首字母跳转 | 从光标下一行起找、找到底绕回，大小写不敏感；重复按同一字母自然在多个匹配间循环，不需要输入缓冲。**与 `j`/`k` 二选一，选了首字母**——面向普通访客更普适，且两者会撞键 |
| 5 | 目录行被选中时 | 右栏保持上一篇：目录没有内容可预览。URL 不动（高亮 ≠ 打开的唯一残留在目录行上，无需文档说明） |
| 6 | 光标初始值 | 指向正在读的那篇（`restoredFile ?? defaultPath`，且必须是可见行）—— 一进站高亮就在当前文章上。旧设计初始为 `null`，第一次按 `↓` 只是「落」到当前篇，同样说不通 |
| 7 | 历史记录粒度 | **合并写入**，策略是纯函数 `shouldCreateHistoryEntry`：点击/`Enter`（`'push'`）无条件新开；开合目录（`'replace'`）从不新开；`↑`/`↓`（`'move'`）距上次新开不足 `MOVE_HISTORY_WINDOW_MS = 1000ms` 就并进上一条 —— 「停留一次 = 一次到访」，按住方向键翻十几篇不会把后退键变成按步数收费 |
| 8 | 窄屏浮层 | 只有确认打开（点击/`Enter`）才收起树；`↑`/`↓` 连续浏览不收，否则浮层反复出没比盖住正文更烦 |
| 9 | 修饰键与 IME | `ctrl`/`meta`/`alt` 一律让路（`Ctrl+F` 搜索、`Alt+←` 后退等）；IME 合成中（`isComposing` / `Process`）不触发首字母跳转；空格不抢，留给正文滚动 |
| 10 | 代码结构 | 导航计算抽成纯函数模块 `tree-nav.ts`（`stepCursorPath` / `arrowRight` / `arrowLeft` / `typeAheadPath`），带单测；`+page.svelte` 只留副作用接线（写 URL、改展开集合） |

## 对 2026-09-11 spec 的推翻

| 旧决策 | 旧结论 | 重评 |
| --- | --- | --- |
| ⛔ 3 光标移动是否换预览 | **不换**。光标只是光标，Enter / 单击才打开 | **推翻**。见决策 1 |
| ⛔ 4 键盘范围 | 只保留 ↑ / ↓ / Enter。Esc、←、→、Backspace 全部移除 | **推翻**。←、→ 回归（决策 2），另加 Home/End/PageUp/PageDn 与首字母跳转（决策 3/4）。Esc、Backspace 依旧不要 |
| 8 不加快捷键 | 左栏开合只有鼠标按钮，不加 `\` / `Ctrl+B` | ✅ 仍然成立：收起整栏依旧只有那条窄边条 |

其余决策（窄边条开关 #6、展开状态生命周期 #7、默认全折叠 #2）不变。

## 文案的连带修改

- `content/readme.md`：**交互说明一句不留** —— 键位表、「箭头只移动高亮」段、「鼠标也是这样」段，以及窄边条 `«`/`»` 的说明段，全部删除。判据只有一条：**还需要解释的交互 = 设计没做对**。窄边条的自解释性由控件自己承担：悬停 tooltip、`aria-label` / `aria-expanded`、hover 变色、指针形状。readme 只说这个站是什么，不说怎么操作。
- `content/projects/yazi-homepage.md`：Features 里「Editor-style cursor」一行改为文件管理器语义。
